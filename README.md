# Выгрузка документов из гостевого доступа ЕМИАС

Сценарий открывает гостевую ссылку в видимом Chrome, вводит код и обходит:

- госпитализации и все страницы документов внутри каждого случая;
- приёмы;
- анализы;
- исследования;
- рецепты;
- справки и медицинские заключения;
- выписки из стационара;
- врачебные консилиумы.

Для каждого раздела выбирается период «всё время», причём для карточек сценарий проверяет получившийся счётчик записей. Для анализов и документов внутри госпитализаций используется первая стрелка прямой загрузки. Приёмы, исследования, рецепты и выписки из стационара сначала открываются правой иконкой просмотра, после чего сценарий нажимает кнопку загрузки внутри окна; печатная копия не считается заменой оригинала. В исследованиях скачиваются все предложенные вложения, включая «заключение + исследование», когда оно доступно. Файлы получают имена вида `2026-08-19 - анализы - название.pdf`. Точные дубли определяются по SHA-256 и повторно не сохраняются.

Каждая категория хранится в отдельной папке: `Госпитализации`, `Приёмы`, `Анализы`, `Исследования`, `Рецепты`, `Справки и медицинские заключения`, `Выписки из стационара`, `Врачебные консилиумы`. Внутри `Госпитализации` автоматически создаётся отдельная подпапка для каждого названия госпитализации, например `ГБУЗ ГКБ № 24 ДЗМ - D64.8 Другие уточненные анемии - bc8eea`. Короткий суффикс предотвращает слияние одинаково обрезанных длинных названий. Новые файлы сохраняются как `дата - название документа.pdf`, без повторения названия госпитализации в имени файла.

При следующем запуске ранее сохранённые PDF автоматически переносятся в соответствующие папки, а пути в реестре и состоянии обновляются.

Для рецептов сценарий сначала открывает основную карточку, затем раскрывает вложенную строку `Рецепты`, выбирает вкладку `все время` и нажимает бумажную иконку просмотра справа у каждой записи. Дата берётся из строки `Выписан: ДД.ММ.ГГГГ`, а в названии файла сохраняется название лекарства.

Пагинация проверяется по внешним кнопкам «Назад/Вперёд» и номеру последней страницы. Раздел считается завершённым только после прохода всех страниц и сверки числа найденных строк со счётчиком на главной странице. Госпитализации обрабатываются в порядке, показанном на скриншотах: открыть карточку, выбрать «за все время», открыть строку стрелкой справа, выбрать вкладку «Все», пройти все страницы документов, нажать «вернуться к списку обращений» и перейти к следующей строке. Кнопка «Вперёд» списка госпитализаций нажимается после завершения всех строк текущей страницы.

## Получение временного доступа к медкарте

Временный доступ создаётся владельцем медицинской карты на сайте ЕМИАС:

1. Перейдите на [страницу электронной медицинской карты](https://lk.emias.mos.ru/medical-records) и авторизуйтесь.
2. В левой панели откройте **Управление профилем**.
3. Выберите **Доступ к записи и медкарте**.
4. Нажмите **Создать временный доступ к медкарте**.
5. В форме временного доступа:
   - выберите нужную электронную медицинскую карту;
   - включите **Все разделы ЭМК**;
   - укажите свой или другой доверенный адрес электронной почты — на него придёт гостевая ссылка;
   - установите необходимый срок доступа;
   - задайте любое понятное наименование доступа.
6. Нажмите **Подтвердить** и введите код подтверждения из SMS, отправленного владельцу медкарты.
7. После создания доступа ЕМИАС покажет пятизначный **код доступа** — это значение для `EMIAS_CODE`.
8. Откройте письмо на указанной почте и скопируйте полученную гостевую ссылку — это значение для `EMIAS_URL`.

Заполните `.env`:

```env
EMIAS_URL=https://lk.emias.mos.ru/guest?token=...
EMIAS_CODE=12345
```

Ссылка и код открывают доступ к медицинским данным. Не публикуйте их, передавайте только доверенному получателю и удалите или отзовите временный доступ после завершения выгрузки.

## Запуск

Понадобятся Node.js 20+ и Google Chrome.

Скопируйте `.env.example` в `.env` и укажите гостевую ссылку `EMIAS_URL` и код `EMIAS_CODE`. Если эти поля пустые, сценарий запросит их в консоли. Значения, уже заданные в окружении, имеют приоритет над файлом.

При первом запуске скрипт установит пакет Playwright. Медицинские документы сохраняются только локально в папке `downloads` рядом со сценарием. Не закрывайте открывшееся окно Chrome до завершения.

### Windows

1. Откройте PowerShell в этой папке.
2. Выполните:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\run.ps1
   ```

### Linux и macOS

1. Откройте терминал в этой папке.
2. Выполните:

   ```bash
   chmod +x run.sh
   ./run.sh
   ```

Ограничить разделы можно так: `./run.sh --only анализы`.

## Результаты и повторный запуск

- `downloads\<категория>\*.pdf` — скачанные документы;
- `downloads\реестр.csv` — дата, тип, название и имя каждого файла;
- `downloads\.emias-state.json` — состояние для продолжения после остановки;
- `downloads\_diagnostics` — снимки экрана при ошибках.

Повторный запуск продолжает выгрузку: уже завершённые действия пропускаются. Если ЕМИАС временно вернул ошибку для конкретной кнопки, эта кнопка будет повторена в следующем запуске.

Чтобы длинная сессия не перегружала страницу, по умолчанию сценарий делает паузу 0,6 секунды после каждого действия и полностью закрывает и заново запускает Chrome после каждых 20 обработанных загрузок. Навигационные паузы и интервалы проверки состояния также уменьшены вдвое; предельные таймауты медленного ответа ЕМИАС сохранены. Перед перезапуском состояние записывается в `.emias-state.json`; затем сценарий повторно входит в ЕМИАС, восстанавливает страницу списка и пропускает уже выполненные действия.

Если кнопка загрузки остаётся в состоянии ожидания (`disabled`, `aria-busy` или вращающийся индикатор) и файл не появляется, сценарий сохраняет состояние, перезагружает страницу и восстанавливает браузерную сессию. Если страница или браузер уже закрылись, выполняется такое же автоматическое восстановление.

## Настройки

Задаются в `.env` (шаблон — `.env.example`):

```env
EMIAS_URL=https://lk.emias.mos.ru/guest?token=...
EMIAS_CODE=73234
EMIAS_BROWSER=chrome                 # либо chromium
EMIAS_HEADLESS=0                     # 1 — без окна
EMIAS_SLOW_MO=10                     # замедление действий, мс
EMIAS_OUTPUT_DIR=                    # пусто = папка downloads рядом со сценарием
EMIAS_ONLY=                          # разделы через запятую, пусто = все
EMIAS_ORGANIZE_ONLY=0                # 1 — только разложить уже скачанные файлы
EMIAS_MAX_PAGES=250
EMIAS_EVENT_SETTLE_MS=350
EMIAS_ACTION_DELAY_MS=600            # пауза между действиями
EMIAS_RESTART_EVERY=20               # 0 отключает перезапуск Chrome
EMIAS_DOCUMENT_LOAD_DELAY_MS=1000    # ожидание содержимого открытого документа
EMIAS_MODAL_APPEAR_TIMEOUT_MS=4000   # ожидание появления окна документа
```

Если установленный Chrome недоступен, выполните `npx playwright install chromium`, затем задайте `EMIAS_BROWSER=chromium` в `.env`.

Страница ЕМИАС иногда меняет внутреннюю разметку. Сценарий использует стабильные `data-testid` из предоставленного HTML и дополнительные эвристики. Итоговые количества обязательно сверьте с напечатанным аудитом и `реестр.csv`.
